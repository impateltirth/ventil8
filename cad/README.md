# CAD files

The AutoCAD source (`.dwg`) lives outside this repo. Export here:

| Export | Format | Purpose |
|---|---|---|
| Each sheet (M-001…) | PDF (`.pdf`) | Viewable construction drawings |
| Full drawing set | DWG (`.dwg`) | Editable source (optional) |
| Schematics | DXF (`.dxf`) | Interchange |

Suggested naming: `ventil8-<sheet>-<rev>.pdf` (e.g. `ventil8-M-101-A.pdf`), matching `docs/drawing-index.md`.
